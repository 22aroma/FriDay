# FriDay (Пятница)

Голосовой ассистент для Windows: офлайн-распознавание русской речи, синтез
речи, погода, музыка, таймеры, будильники, калькулятор и смена обоев рабочего
стола.

## Возможности

- **Активация по слову «Пятница»** — команду можно сказать сразу или отдельно,
  после активации.
- **Распознавание речи** — офлайн, [GigaAM-v3](https://huggingface.co/handy-computer/gigaam-v3-e2e-rnnt-gguf)
  через [transcribe.cpp](https://github.com/handy-computer/transcribe.cpp).
- **Синтез речи** — [Silero TTS](https://github.com/snakers4/silero-models),
  модель `v5_4_ru`, голос `baya`.
- **VAD** — [Silero VAD](https://github.com/snakers4/silero-vad).
- **Погода** — OpenWeatherMap (нужен собственный API-ключ), город можно называть
  в запросе.
- **Музыка** — поиск и воспроизведение через `yt-dlp`.
- **Будильник и таймер** — голосовая установка; таймер можно отменить.
- **Калькулятор** — голосовые вычисления.
- **Обои** — случайная картинка из указанной папки или файла (Windows 11 22H2+).
- **Трей** — управление из системного трея.
- **Пресеты приложений** — запуск сохранённых наборов программ.
- **Память** — команда без ключевого слова запоминается на некоторое время.

## Команды

| Фраза | Действие |
|---|---|
| «Пятница, какая погода в Москве?» | Погода |
| «Пятница, смени обои» | Случайные обои из указанной папки или файла |
| «Пятница, включи музыку джаз» | Поиск и воспроизведение музыки |
| «Пятница, следующий трек» / «стоп» | Управление музыкой |
| «Пятница, таймер на 5 минут» | Таймер |
| «Пятница, таймер стоп» | Отмена таймера |
| «Пятница, будильник на 7 часов 30 минут» | Будильник |
| «Пятница, сколько будет 2 плюс 2?» | Калькулятор |
| «Пятница, повтори» | Повтор последнего ответа |
| «Пятница, выключись» | Завершение работы ассистента |
